# Дизайн Azati для бота

Оригинал: https://www.azati.com/ (проверен 28.09.2026).
Локальная копия главной страницы: `D:\azati-site-reference`. Это отдельный проект на основе установленного шаблона `D:\ai-website-cloner-template`; исходный шаблон не изменён.

## Как посмотреть и обновить копию

```powershell
cd D:\azati-site-reference
npm run dev
```

Откройте `http://127.0.0.1:3000/`. Начальная страница перенаправляет на локальный снимок `/snapshot/index.html`. Чтобы обновить его с оригинала:

```powershell
python scripts\mirror_azati.py
npm run check
```

Снимок хранит HTML и публичные статические файлы главной страницы локально. Формы отправки отключены, сторонние скрипты удалены. Ссылки на другие разделы открывают оригинальный сайт, поскольку они не входят в снимок.

## Что перенесено в приложение

| Оригинал Azati | Применение в боте |
| --- | --- |
| Тёмно-синий `#060b1a` | Основа Mini App, сайдбар и вход служебных панелей |
| Оранжевый `#ff6e20` | Фирменная деталь, надписи и акценты |
| Бирюзовый `#167271` | Основные действия, выбранные вкладки |
| Manrope | Основной текст во всех интерфейсах |
| Plus Jakarta Sans 800 | Крупные заголовки |
| IBM Plex Serif italic | Небольшие декоративные элементы Mini App |
| Актуальный SVG-логотип | Шапки и экраны входа |

Mini App остаётся тёмным и адаптированным к экрану Telegram. Панели бармена и администратора сохраняют плотную рабочую компоновку и светлое поле для чтения заказа, меню и форм. Фирменные цвета и шрифты не меняют API, права доступа и сценарии обработки заказов.

## Файлы

- `miniapp/src/styles.css`, `miniapp/src/App.tsx` — оформление гостевого интерфейса.
- `app/web/static/panels-azati.css`, `app/web/templates/panel_base.html` — оформление панелей.
- `app/web/static/fonts/`, `app/web/static/images/azati-logo-current*.svg` — локальные ассеты.

Проверки: `miniapp/npm run build` и `D:\azati-site-reference/npm run check` успешно выполнены. Панели `/staff` и `/admin` просмотрены в браузере на отдельной локальной SQLite-базе с демонстрационным меню. Реальный запуск внутри Telegram на телефоне ещё требует проверки в клиенте Telegram.
